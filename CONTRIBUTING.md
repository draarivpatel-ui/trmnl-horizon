# Contributing to TRMNL-Horizon

Contributions to the self-hosted TRMNL BYOS server, 800x480 dithering pipeline, and `.liquid` plugin templates are welcome.

## Development Workflow

1. Fork the repository and create a feature branch.
2. Run the automated test suite with `node --test` (all 46+ tests must pass).
3. Start the local BYOS server with `node server.js` and verify the 800x480 workbench at `http://localhost:8080`.
4. Submit a pull request with a clear description of your changes.
