# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

Please report security vulnerabilities via GitHub Security Advisories at `https://github.com/draarivpatel-ui/trmnl-horizon/security/advisories/new`. You will receive an acknowledgment within 48 hours.
